𖹭.ᐟ.ᐟO SAAT (Sistema de Apoio para Astronautas) é um Software desenvolvido para o suporte de viagens espaciais. Seu principal propósito é calcular a distância em horas/dias de ponto A para ponto B e a única coisa que o tripulante deve fazer é colocar no sistema o nome completo, a distância até o destino e a velocidade máxima da nave. Além disso, o programa foi escrito em uma línguagem acolhedora, para aliviar a solidão no espaço.
